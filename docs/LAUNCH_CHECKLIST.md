# 정식 출시 전 체크리스트

> 데모라서 단순하게 처리했거나 미뤄 둔 일. 끝난 항목은 [x] 로 바꾸고 날짜를 적는다.

## 꼭 해야 할 것
- [ ] **이메일 인증 다시 켜기**: Supabase → Authentication → Email → Confirm email. (앱은 이미 "확인 메일을 보냈어요" 안내를 처리함)
- [ ] **약관·개인정보처리방침 법률 검토**: `apps/mobile/src/constants/legal.ts` 는 초안. 처리 위탁(Supabase 등), 문의처 기재.
- [ ] **거래 기록 보관**: 지금은 탈퇴하면 주문·신청 기록까지 지워진다. 전자상거래법상 보관 기간이 있으므로 분리 보관 구조 필요.
- [ ] **실제 결제(PG) 연동**: 주문·구독·살균·안전결제 모두 가짜. 결제 확인·웹훅은 Edge Functions 로 (secret 키는 서버에만).
- [ ] **사진 위치 정보 삭제 확인**: 매물 사진 재인코딩 후 EXIF/GPS 가 실제로 빠지는지 확인.
- [ ] **예시 데이터 정리**: 가짜 회원 `seed01~15@mompick-demo.dev` 와 그 글·매물 삭제 (Auth 사용자 삭제 시 연결 데이터도 함께 지워짐).
- [ ] **운영 설정값 확인**: `app_settings` 의 `best_post_min_likes`(10), `report_hide_threshold`(3) 등이 테스트용 값(1)으로 남아 있지 않은지.
- [ ] **`.env.local` 정리**: `SUPABASE_PW` 같은 비밀 값이 남아 있지 않은지.
- [ ] **유출 비밀번호 차단 켜기**: Supabase → Authentication → 비밀번호 보안의 leaked password protection (보안 점검 경고).
- [ ] **시험 흔적 정리**: "검증용 테스트 업체"(반려), seed01 검증용 주문, 데모 업체 연락처(`demo@mompick-demo.dev`).
- [ ] **RLS 성능 정리**: 같은 테이블에 읽기 정책이 여러 개라는 성능 경고(multiple permissive policies) — 데이터가 늘기 전에 정책 합치기.

## 검토할 것
- [ ] **DB 리전**: 지금 시드니(ap-southeast-2). 한국 사용자 속도를 위해 서울(ap-northeast-2) 이전 검토.
- [ ] **등급 하락 규칙**: 지금은 내려가지 않음 (예: 구독 해지 후에도 숲 맘).
- [ ] **쿠폰 환불**: 살균 신청 취소 시 쓴 쿠폰이 돌아오지 않음. 주문 취소 기능 없음.
- [ ] **후기 기능**: "구매 확인 후기", "혜택 제공" 표시 아직 없음 (AGENTS.md 원칙).
- [ ] **동네 확장**: 서울 외 지역 행정동 추가.
- [ ] **아이폰**: Apple 개발자 계정(연 $99) → TestFlight → App Store 심사.
- [ ] **안드로이드 정식**: Google Play 개발자 계정($25) → production 빌드(AAB) → 심사.
- [ ] **웹 고정 주소**: `eas deploy --prod` (지금은 미리보기 주소만).
