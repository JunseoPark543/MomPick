# 대표 페이지 사진 넣는 곳

이 폴더에 아래 이름으로 JPG 파일을 넣으면 대표 페이지의 그 자리에 사진이 나온다.
사진이 없으면 그 자리에는 앱 화면이 대신 보인다. 넣은 뒤 다시 빌드·배포하면 반영된다.

| 파일 이름 | 들어가는 자리 | 어울리는 장면 (예시) |
|---|---|---|
| `community.jpg` | 메인 — 동네·동기 커뮤니티 | 놀이터·카페에서 이야기 나누는 엄마들, 유모차를 끌고 걷는 모습 |
| `used.jpg` | 메인 — 유아용품 중고거래 | 아기 옷·장난감을 건네는 손, 문 앞에서 물건을 주고받는 모습 |
| `market.jpg` | 메인 — 이유식·육아용품 특가 | 식탁 위 이유식 용기, 장바구니 속 기저귀·물티슈 |
| `sterilize.jpg` | 메인 — 살균 서비스 | 깨끗한 유모차·카시트, 햇빛 드는 현관의 유모차 |
| `partners.jpg` | 입점 안내 — 맨 위 넓은 사진 | 포장을 마친 상품 상자, 상품을 정리하는 판매자의 손 |

## 사진 기준
- **가로 사진**, 가로 1600px 이상 (화면 비율 약 27:16, 입점 안내 맨 위는 27:11 로 잘림)
- **아이 얼굴이 나오지 않게** (손, 뒷모습, 육아용품 위주) — 맘픽 개인정보 원칙
- 어른 얼굴이 나오면 본인 동의를 받은 사진만
- 직접 찍었거나 사용 권리가 있는 사진만 (다른 서비스·브랜드 로고가 크게 보이지 않게)
